公開ツール一覧

AIエージェントやアプリケーションから呼び出せる、BLUE TICKER の全機能一覧です。REST API と MCP ツールは同じカタログを共有しています。

通常の API は Cloudflare Access 経由の認可が必要です（summary.html の実データ検索は認証不要の限定公開エンドポイントです）。

企業を探す

discovery 銘柄コードや業種名がまだ分からないときの入り口。

企業検索search-companies
search_companies

銘柄コードまたは名称で企業を検索します。

RESTGET/v1/companies?q=
例GET /v1/companies?q=トヨタ

銘柄コードが未知のときに最初に使う。ヒットした code を以降の financials/filings 等に渡す。

業種一覧list-sectors
REST専用

東証33業種の一覧と業種別銘柄数を返します。

RESTGET/v1/sectors
例GET /v1/sectors

業種名を知る・業種別件数を見るときに使う。

業種別銘柄検索search-by-sector
search_by_sector

東証33業種で銘柄を検索します。業種名の部分一致で絞り込めます。

RESTGET/v1/sectors/{sector}/companies?limit=20
例GET /v1/sectors/電気機器/companies?limit=20

業種から銘柄候補を集めるときに使う。業種名が不明なら先に list-sectors。

提出書類一覧get-filings
get_filings

銘柄コードに紐づく EDINET 書類一覧を取得します。

RESTGET/v1/companies/{code}/filings?max_years=5
例GET /v1/companies/6103/filings?max_years=5

有報・半期などの doc_id を知るときに使う。filing-content/breakdown の doc_id 指定の前段。

財務サマリーを取る

summary 格納済みの財務諸表の数値（水準値）をそのまま返す。

通期財務サマリーget-financials
get_financial_summary

銘柄コードの財務サマリーを年度別に返します（格納済みデータのみ）。損益・CF・バランスシート・収益性指標（水準値）を含む。直近5年分。前年差・要因分解は get_waterfall へ。金額単位は百万円(JPY)、比率は%、株主指標は円。

RESTGET/v1/companies/{code}/financials?years=5
例GET /v1/companies/6103/financials?years=5

増減を分析する

waterfall 独自の分析手法に基づいた前年差・要因分解の計算値。

通期増減分析get-waterfall
get_waterfall

銘柄コードの増減分析（前年差分解）を年度別に返します。get_financial_summary と同じ水準値に加え、事業利益ウォーターフォール（売上差/粗利率差/販管費差影響）、ROIC・ROE前年差の要因分解、ネットキャッシュ前年差、運転資本・CCC前年差（DSO/DIO/DPO差影響）を含む。直近5年分。金額単位百万円(JPY)、比率%、日数は日。

RESTGET/v1/companies/{code}/waterfall?years=5
例GET /v1/companies/6103/waterfall?years=5

有報の本文を読む・事業別内訳を見る

filing / breakdown 有価証券報告書のテキストと、構造化された事業別売上高。

有報セクション本文get-filing-content
get_filing_content

EDINET 書類からセクションテキストを抽出します（格納済みデータのみ）。doc_id 省略時は最新の有価証券報告書。sections 省略時は全セクション。利用可能セクション: business_risks, mda, capex_overview, major_facilities, facility_plans, research_and_development, segments, geography。

RESTGET/v1/companies/{code}/filing-content?sections=mda,business_risks
例GET /v1/companies/6103/filing-content?sections=mda,business_risks
事業別・地域別売上内訳get-breakdown
get_breakdown

有価証券報告書から事業別/地域別売上高の内訳を取得します（格納済みデータのみ）。対象は日経225構成銘柄に限る。axis は business（既定）/ geography に対応。

RESTGET/v1/companies/{code}/breakdown?axis=business
例GET /v1/companies/6758/breakdown?axis=geography
認証について: 通常の API は Cloudflare Access 経由の認可が必要です。MCP コネクタとしての接続方法はMCPページを参照してください。summary.html の実データ検索は、この一覧を試すための認証不要の限定公開エンドポイントです。
