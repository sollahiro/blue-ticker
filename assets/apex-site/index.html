どうやって使い始める？

アカウント登録は不要です。接続先を登録して、ブラウザで一度認可するだけです。現在は無料でご利用いただけますが、今後一部機能の有料化を検討しています。

  1. 1

    コネクタとして登録する

    Claude Desktop / Claude.ai / Grok の「カスタムコネクタを追加」で接続先を入力します。スマートフォンアプリではなく、Web版での操作が必要です。

    https://mcp.sollahiro.com
  2. 2

    ブラウザで認可する

    初回接続時にブラウザが開き、Cloudflare Access 経由で認可します（Managed OAuth）。以降はそのまま会話の中でツールを呼べます。

curl・CI から機械的に呼び出せる REST API も公開予定です（https://api.sollahiro.com）。
