Blue Ticker 免責とプライバシー方針

最終更新: 2026-09-19
運営: 個人開発（Sorahiro Shuto）

免責

Blue Ticker は、EDINET に提出された有価証券報告書などの公開情報から、財務の数字や会社の説明を抽出・加工・再構成して表示するアプリです。

投資の勧誘、投資助言、金融商品の売買の推奨ではありません。

抽出・加工・再構成の過程により、表示は EDINET の原本と一致しないことがあります。提出後に訂正報告書が出ることもあり、情報の完全性、正確性、最新性は保証しません。

投資その他の金融上の判断は、原本やその他の資料も確認したうえで、ご自身の責任において行ってください。

プライバシー方針

Blue Ticker はアカウントを作りません。ログインもありません。広告 SDK や、利用者の行動を追跡する目的の SDK は使いません。Crashlytics、Sentry、TelemetryDeck、Firebase などの解析・クラッシュ報告サービスも使いません。

リストと iCloud

次の情報は、アプリの機能のために端末内へ保存します。同じ Apple ID でサインインしている端末のあいだで同期するため、iCloud（CloudKit）にも保存します。Blue Ticker のサーバーへは送りません。

  • リストに入れた銘柄
  • 保有の株数、取得単価、証券会社、口座の区分

iCloud にサインインしていない場合は、端末の中だけに置きます。アプリを削除しても、iCloud 上のリストは残ることがあります。iCloud から消すには、同期している端末でリストを空にするか、Apple の iCloud 設定からこのアプリのデータを削除してください。

サーバーへ送るもの

検索や銘柄・財務情報の表示のため、運営者のサーバーへ HTTPS でリクエストを送ります。アプリが載せるのは、検索語、銘柄コード、スクリーニング条件など、表示に必要な内容です。

リストの保有株数、取得単価、証券会社、口座の区分は、このリクエストに含めません。

正規のアプリであることを確認し、不正利用を防ぐため、Apple の App Attest を使います。広告配信や行動追跡には使いません。

通信の過程で、接続元の IP アドレスなどがサーバー側から見える場合があります。運営者のデータベースに IP アドレスは保存していません。

サーバー上の保存とログ

App Attest で使う鍵の識別子と公開鍵は、不正利用の防止のためにサーバーへ残します。氏名や Apple ID には結び付けておらず、アカウントもありません。アプリを消すと端末側の鍵は消えますが、サーバー上の識別子は自動では消えません。本人の行を特定できないため、個別の削除請求には原則として応じられません。

障害対応とセキュリティのため、ホスティング（Cloudflare）の呼び出しログが残ることがあります。日時、リクエストの内容（検索語や銘柄コードを含むことがあります）、応答の状態、接続に関する情報が入る場合があります。保持期間は Cloudflare のプランに従い、最大 7 日です（無料プランは 3 日）。

第三者サービス

機能の提供のため、ホスティングに Cloudflare を、アプリの確認とリストの同期に Apple（App Attest および iCloud）を使います。渡す情報は、それぞれの機能に必要な範囲に限ります。

削除

端末内の認証情報は、アプリを削除すると端末から消えます。リストと保有情報は iCloud に残ることがあるため、上記の「リストと iCloud」のとおり削除してください。呼び出しログは、上記の保持期間のあと消えます。

子どもの利用

13 歳未満の子どもを対象にしたサービスではありません。

方針の変更

サービスの内容やデータの取り扱いが変わるときは、この方針を更新します。重要な変更がある場合は、このページの最終更新日を更新します。
