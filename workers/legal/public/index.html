Blue Ticker 免責事項およびプライバシーポリシー

最終更新: 2026-09-21
運営: Sorahiro Shuto

1. 免責事項

Blue Ticker は、金融庁の開示システム（EDINET）などに公開されている有価証券報告書などから、財務の数字や会社の説明を抽出・加工・再構成して表示する閲覧補助アプリです。会社の説明には、自動処理や生成AI等による要約・再構成が含まれることがあります。

  • 投資勧誘ではありません: 表示する情報は、投資の勧誘、投資助言、特定の金融商品の売買の推奨ではありません。運営者は、金融商品取引法上の金融商品取引業者（投資助言・代理業者等）の登録を受けていません。
  • 情報の正確性: 抽出・加工・正規化・自動再構成の過程や、訂正報告書の反映タイミングにより、表示が EDINET の原本や企業の公式開示と一致しないことがあります。完全性、正確性、適時性は保証しません。
  • 判断はご自身で: 投資その他の金融上の判断は、金融庁の EDINET や各企業の公式情報・原本を確認したうえで、ご自身の責任で行ってください。利用に伴う責任の範囲は利用規約の定めに従います。

2. プライバシーポリシー

アカウント作成やログインはありません。広告配信 SDK や、利用者の行動追跡を目的としたサードパーティ製 SDK、解析・クラッシュ報告サービスは使っていません。

2.1 端末内および iCloud でのデータ保存

次のデータは、機能のために端末内へ保存します。同じ Apple ID でサインインしている端末のあいだで同期するため、Apple の iCloud（CloudKit）も使います。運営者のサーバーへ送ったり、保存したりすることはありません。

  • リストに追加した銘柄情報
  • 保有株数、取得単価、利用証券会社、口座区分

注意: iCloud にサインインしていない場合、データは端末内だけに残ります。アプリを削除しても iCloud 上のデータが残ることがあります。消したいときは、アプリ内でリストを空にするか、iOS の「設定」> [Apple ID] >「iCloud」>「アカウントのストレージを管理」から Blue Ticker のデータを削除してください。

2.2 運営サーバーへの通信

検索や銘柄・財務情報の表示のため、運営者のサーバーへ HTTPS（暗号化）で通信します。リクエストに載せるのは、検索キーワード、銘柄コード、スクリーニング条件など、画面表示に必要な情報です。

  • 送らないもの: リスト内の保有株数、取得単価、証券会社、口座区分などの個人設定・資産データは、この通信に含めません。
  • 正規利用の確認: 不正利用を防ぎ、正規アプリからのアクセスであることを確認するため、Apple の App Attest と、有効期限の短い匿名トークンを使います。広告配信や行動追跡には使いません。
  • IP アドレス: 通信の過程で、接続元の IP アドレスなどがサーバー側に一時的に届きます。運営者のデータベースにIPアドレスを永続的に保存することはありません。

2.3 サーバー上のログおよび識別子の保持

  • 認証用識別子: App Attest で使う鍵の識別子と公開鍵は、不正利用防止のためサーバー上に保持します。氏名や Apple ID などの個人情報には結び付けておらず、アカウントもありません。広告用識別子ではなく、解析・クラッシュ報告 SDK による追跡にも使いません。サーバー上の識別子は自動では削除されません。氏名やアカウントが無いため、個別の削除請求には原則として応じられません。
  • アクセスログ: 安定運用とセキュリティのため、ホスティング（Cloudflare）でアクセスログが一時的に残ることがあります。ログにはアクセス日時、リクエスト内容（検索語や銘柄コードを含むことがあります）、レスポンス状態、通信接続情報が入ります。Cloudflare の仕様に基づき、最大 7 日間保持したあと自動で消えます。

2.4 第三者サービスの利用

機能のために、次の外部サービスを使っています。渡すデータは、それぞれの機能に必要な範囲に限ります。

  • Cloudflare: ホスティングと通信セキュリティ
  • Apple（App Attest / iCloud）: アプリの正規利用の確認、および端末間でのデータ同期

2.5 データの削除について

  • アプリをアンインストールすると、端末内のアプリ領域に保存されたデータ（リストや保有情報など）は消えます。一方、iOSのKeychainに保存された匿名トークンやApp Attestの記録は、アプリ削除だけでは消えない場合があります。OS または利用者の操作で消えるまで残ることがあります。
  • iCloud 上に残ったデータは、「2.1 端末内および iCloud でのデータ保存」の手順で削除してください。
  • 通信ログは、保持期間（最大 7 日間）が過ぎると自動で消えます。
