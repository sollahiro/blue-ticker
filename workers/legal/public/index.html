1. 免責事項

有報LAB は、金融庁の開示システム（EDINET）などに公開されている有価証券報告書などから、財務の数字や会社の説明を抽出・加工・再構成して表示する閲覧補助サービスです。iOS アプリと、Claude などの AI アシスタントから使うコネクタ（「3. 有報LAB コネクタ」）があります。表示するデータは、運営者が運営する有報LAB API（YuhoLAB API）から取得します。会社の説明には、自動処理や生成AI等による要約・再構成が含まれることがあります。

  • 投資勧誘ではありません: 表示する情報は、投資の勧誘、投資助言、特定の金融商品の売買の推奨ではありません。運営者は、金融商品取引法上の金融商品取引業者（投資助言・代理業者等）の登録を受けていません。
  • 情報の正確性: 抽出・加工・正規化・自動再構成の過程や、訂正報告書の反映タイミングにより、表示が EDINET の原本や企業の公式開示と一致しないことがあります。完全性、正確性、適時性は保証しません。
  • 判断はご自身で: 投資その他の金融上の判断は、金融庁の EDINET や各企業の公式情報・原本を確認したうえで、ご自身の責任で行ってください。利用に伴う責任の範囲は利用規約の定めに従います。

2. プライバシーポリシー（iOS アプリ）

この章は iOS アプリについて定めます。コネクタについては「3. 有報LAB コネクタ」をご覧ください。iOS アプリには、アカウント作成やログインはありません。広告配信 SDK や、利用者の行動追跡を目的としたサードパーティ製 SDK、解析・クラッシュ報告サービスは使っていません。

2.1 端末内および iCloud でのデータ保存

次のデータは、機能のために端末内へ保存します。同じ Apple ID でサインインしている端末のあいだで同期するため、Apple の iCloud（CloudKit）も使います。運営者のサーバーへ送ったり、保存したりすることはありません。

  • リストに追加した銘柄情報
  • 保有株数、取得単価、利用証券会社、口座区分

注意: iCloud にサインインしていない場合、データは端末内だけに残ります。アプリを削除しても iCloud 上のデータが残ることがあります。消したいときは、アプリ内でリストを空にするか、iOS の「設定」> [Apple ID] >「iCloud」>「アカウントのストレージを管理」から有報LAB のデータを削除してください。

2.2 運営サーバーへの通信

検索や銘柄・財務情報の表示のため、運営者のサーバーへ HTTPS（暗号化）で通信します。リクエストに載せるのは、検索キーワード、銘柄コード、スクリーニング条件など、画面表示に必要な情報です。

  • 送らないもの: リスト内の保有株数、取得単価、証券会社、口座区分などの個人設定・資産データは、この通信に含めません。
  • 正規利用の確認: 不正利用を防ぎ、正規アプリからのアクセスであることを確認するため、Apple の App Attest と、有効期限の短い匿名トークンを使います。広告配信や行動追跡には使いません。
  • IP アドレス: 通信の過程で、接続元の IP アドレスなどがサーバー側に一時的に届きます。運営者のデータベースにIPアドレスを永続的に保存することはありません。

2.3 チャットで送る質問

銘柄画面のチャットでは、数字だけで答えられる質問は端末内の言語モデル（Apple Intelligence）で答え、その質問は端末の外へ送りません。有報の内容（事業の理由、方針、リスク、内訳など）に関わる質問は、回答を作るために運営者のサーバーへ送ります。

  • 送るもの: 質問の文章、同じ画面での直前のやりとり（数件）、銘柄コード
  • 外部の AI サービス: 運営者のサーバーは、回答を生成するために、質問と有報から取り出した文章を外部の AI サービス（OpenRouter を経由した言語モデル）へ渡します。学習やデータの保持を行う提供元は選ばない設定にしています。
  • 保存: 運営者は、質問と回答の本文をデータベースに保存しません。利用回数の上限を守るため、端末ごとの利用回数だけを記録します。この回数は個人と結び付けていません。
  • 注意事項: 質問には、氏名や連絡先、口座の情報など、個人を特定できる情報を含めないようお願いします。

2.4 サーバー上のログおよび識別子の保持

  • 認証用識別子: App Attest で使う鍵の識別子と公開鍵は、不正利用防止のためサーバー上に保持します。氏名や Apple ID などの個人情報には結び付けておらず、アカウントもありません。広告用識別子ではなく、解析・クラッシュ報告 SDK による追跡にも使いません。サーバー上の識別子は自動では削除されません。氏名やアカウントが無いため、個別の削除請求には原則として応じられません。
  • アクセスログ: 安定運用とセキュリティのため、ホスティング（Cloudflare）でアクセスログが一時的に残ることがあります。ログにはアクセス日時、リクエスト内容（検索語や銘柄コードを含むことがあります）、レスポンス状態、通信接続情報が入ります。Cloudflare の仕様に基づき、最大 7 日間保持したあと自動で消えます。

2.5 第三者サービスの利用

機能のために、次の外部サービスを使っています。渡すデータは、それぞれの機能に必要な範囲に限ります。

  • Cloudflare: ホスティングと通信セキュリティ
  • Fly.io および Neon: 有報LAB API のサーバーとデータベースのホスティング（保存するのは開示書類から作ったデータで、利用者のデータではありません）
  • Apple（App Attest / iCloud）: アプリの正規利用の確認、および端末間でのデータ同期
  • OpenRouter および言語モデルの提供元: チャットでサーバーへ送った質問の回答の生成

2.6 データの削除について

  • アプリをアンインストールすると、端末内のアプリ領域に保存されたデータ（リストや保有情報など）は消えます。一方、iOSのKeychainに保存された匿名トークンやApp Attestの記録は、アプリ削除だけでは消えない場合があります。OS または利用者の操作で消えるまで残ることがあります。
  • iCloud 上に残ったデータは、「2.1 端末内および iCloud でのデータ保存」の手順で削除してください。
  • 通信ログは、保持期間（最大 7 日間）が過ぎると自動で消えます。

3. 有報LAB コネクタ（AI アシスタント向け）

有報LAB コネクタ（以下「コネクタ」）は、Claude などの AI アシスタントから有報LAB のデータを読み出すための接続先です（https://mcp.yuholab.com/mcp、Model Context Protocol）。この章は、コネクタでの個人情報の扱いを定めます。

3.1 接続時のサインイン

コネクタを AI アシスタントに接続するとき、Google のアカウントでサインインします。

  • 受け取るもの: サインインの結果として Google が発行する、Google の中での利用者識別子です。メールアドレス、氏名、プロフィール画像は求めておらず、保存しません。
  • 保存するもの: 利用者識別子そのものは保存せず、運営者の秘密鍵で計算した一方向のハッシュ値だけを保存します。あわせて、運営者が割り当てる内部 ID（利用者・アカウント）、接続の記録（接続した AI アシスタント、作成日時、有効期限）、再接続に使うトークンのハッシュ値を保存します。
  • サインインを求める理由: iOS アプリでは、端末の正規アプリであることを Apple の App Attest で確認しています。AI アシスタントから使うコネクタでは、この端末の確認ができません。そのため、過剰なアクセスを制限し、不正な利用を防ぐために、接続する人ごとにサインインを求め、同じ人かどうかを見分けます。
  • 使う目的: 同じ人からの接続を同じ利用者として扱うこと、接続の取り消し、利用回数の上限の適用、不正利用の防止に限って使います。

3.2 AI アシスタントから届く情報

  • 受け取るもの: AI アシスタントがコネクタのツールを呼び出すときの、ツール名と引数（銘柄コード、会社名などの検索語、年数、内訳の種類など）です。
  • 受け取らないもの: 会話の本文、ファイル、AI アシスタントに登録した利用者の情報は、コネクタには届きません。ただし、AI アシスタントが会話の内容を検索語などの引数に入れることがあります。引数に個人を特定できる情報を含めないようお願いします。
  • AI アシスタントでの扱い: 会話やコネクタからの応答が AI アシスタントの中でどう扱われるかは、その提供元（Claude の場合は Anthropic）の方針に従います。

3.3 ログと利用回数

  • 利用回数: 利用回数の上限を守るため、内部 ID ごと・ツールごとの回数を記録します。
  • ログ: 安定運用とセキュリティのため、ホスティング（Cloudflare）に処理のログが残ります。ログには日時、内部 ID、ツール名、リクエスト内容（銘柄コードや検索語を含むことがあります）、応答の状態が入ります。最大 7 日間保持したあと自動で消えます。
  • 使わない目的: 広告配信、行動追跡、第三者への販売には使いません。

3.4 第三者サービスの利用

  • Google: 接続時のサインイン
  • Cloudflare: コネクタと認証サーバーのホスティング、3.1 のデータの保存
  • Fly.io および Neon: 有報LAB API のサーバーとデータベースのホスティング（ツールの引数を処理します）

これらの事業者の一部は日本国外のサーバーで処理を行います。運営者がこれらの事業者に 3.1 や 3.2 のデータを提供・販売することはありません。

3.5 接続の解除と削除

  • 接続の解除: AI アシスタントの設定からコネクタを外してください。90 日間使われなかった接続は自動で失効します。
  • 削除の依頼: 3.1 で保存したデータは、メールアドレスや氏名に結び付けておらず、運営者の側から特定の個人のデータを見つけ出すことができません。そのため、個別の削除の依頼には原則として応じられません。接続を解除すると、その接続は使えなくなり、再接続のためのトークンも無効になります。ご不明な点は support@yuholab.com へご連絡ください。
  • ログ: 保持期間（最大 7 日間）が過ぎると自動で消えます。

4. データの出所

有報LAB が表示・提供するデータは、EDINET（金融庁）で公開されている開示書類をもとに、運営者が抽出・加工・再構成して作成したものです。EDINET の原本そのものではありません。

上記をもとに、運営者が編集・加工して作成しています。編集・加工した内容は、国（金融庁）が作成した未加工の情報ではありません。
