わかりやすい説明

ここから先は、規約本文の要約ではありません。Blue Ticker を使う人が、何を見てよく、何を期待してはいけないかを読むための説明です。

Blue Ticker は何か

Blue Ticker は、日本の上場会社が EDINET に提出した有価証券報告書などから、財務の数字や会社の短い説明を取り出し、加工して見せる iOS アプリです。

アプリは画面を出すために、運営者のサーバーへ通信します。これはアプリの表示用であり、第三者向けの REST 製品ではありません。

株価のリアルタイム配信、ニュース、売買、口座開設、投資の助言はしていません。開発者が手元で使う MCP や、凍結している ChatGPT Apps 連携は、このページが説明する製品には含みません。

投資の勧誘のサービスではありません。金融商品取引法上の登録（金融商品取引業者、投資助言・代理業など）はありません。

何を許しているか

アプリを入れた人は、次のことができます。

  • 日本株の銘柄を名前で探す、業種や条件で探す
  • 格納済みの年次財務（業績・資産・効率性）を見る
  • 前年差の要因分解（事業利益 / ROIC / ROE）を見る
  • 気になる会社をリストに入れる
  • 保有の株数・取得単価・証券会社・口座の区分を自分で入力し、保有株数に応じた業績（純利益・純資産・投資元本・ファンドROE）を見る

リストと保有の入力は、あなたの端末と、同じ Apple ID の iCloud に置きます。Blue Ticker のサーバーへは送りません。

利用にアカウント作成は不要です。ログインもありません。いま、利用料金は発生しません。将来料金を設ける場合は、この利用規約を改定してからにします。

何をしないか（期待しないでほしいこと）

Blue Ticker は、次のものではありません。

  • 投資の勧誘、投資助言、売買の推奨、証券会社や銀行のサービス
  • 株価・時価・チャートの配信
  • ニュースや外部サイトの記事の掲載
  • 税務・確定申告・NISA の適否を判定する道具（口座区分はあなたがメモする項目です）
  • すべての上場会社・すべての年度が必ず揃うデータベース（未取り込みは表示されません）
  • 有価証券報告書の原本の代わり（原本は EDINET 側にあります。本サービスはあくまでその補助です）
  • 第三者向けの REST API 製品

ファンド画面の数字は、あなたが入れた株数に、最新の年次 EPS / BPS などを掛けた目安です。時価評価ではありません。

データの出所

元になっているのは、金融庁の電子開示システム EDINET に提出された有価証券報告書などの公開情報です。対象市場は日本（JP）です。海外開示や別市場の報告書は扱いません。

取り出したあと、次のような加工をしています。

  • 財務諸表や注記から、年次のサマリーや内訳を組み立てる
  • 前年差の要因分解を計算する
  • 有報の「事業の内容」などから、短い会社説明を生成する（生成には言語モデルを使います。原文の全文ではありません）
  • 企業や業種ごとに独自の開示項目があるものを、比較できるよう売上高・営業利益のような一般的な項目名に寄せる

表示の単位は、金額が百万円、比率がパーセントであることが多いです。画面上の単位表示に従ってください。画面の項目名が、その会社の開示上の科目名と一致しない場合があります。

EDINET や提出会社とは資本関係も提携もありません。公式見解でもありません。

表示が原本と違うことがある

本サービスは有価証券報告書の原本の補助です。利用者は必ず原本も合わせて見てください。抽出・加工・再構成・正規化の過程で、画面の数字や文言は原本と一致しないことがあります。提出後に訂正報告書が出ることもあり、取り込みが追いついていないことがあります。事業利益の分解は、開示されている営業利益と一致しない場合があります。

補助である以上、表示を参考にして行った投資の結果について、運営者は損害を補填しません。原本との違いから生じた損害も同様です。投資その他の判断は、原本やその他の資料も確認したうえで、ご自身の責任で行ってください。

やってはいけないこと

次のような使い方はしないでください。

  • アプリの認証（App Attest など）を迂回する、他人の端末になりすます
  • 表示目的を超えて、大量に機械的に取りに行く、サービスを妨げる
  • Blue Ticker の画面や出力を、EDINET や提出会社の公式データであるかのように再配布する
  • このサービスを、無登録の投資助言や、他人への投資推奨の道具として使う
  • 開発用の入口や内部の仕組みに、製品として入り込もうとする

普通にアプリを開いて銘柄を見る分には、禁止事項に当たりません。
