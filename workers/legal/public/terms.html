Blue Ticker 利用規約

最終更新: 2026-09-20
運営: Sorahiro Shuto

第1条（適用）

1. 本規約は、Sorahiro Shuto（以下「運営者」）が提供するサービス「Blue Ticker」（以下「本サービス」）の利用条件を定めるものです。

2. 利用者は、本サービス（アプリ）をダウンロード、インストール、または使用を開始した時点で、本規約に同意したものとみなされます。なお、本サービスに利用者アカウントの登録機能はありません。

3. 個人情報の取扱いについては、別途定める「プライバシー方針」が優先して適用されます。本規約とプライバシー方針の内容が矛盾する場合は、個人情報の取扱いに関してはプライバシー方針が、その他の事項に関しては本規約が優先して適用されます。

4. 本アプリは、App Store から入手して使用する利用者を対象とします。App Store から入手して利用する場合、Apple Inc.（以下「Apple」）が定める利用条件もあわせて適用されます。Apple は本規約の当事者ではありません。

第2条（定義）

本規約において使用する用語の定義は、以下のとおりとします。

1. 「本アプリ」：運営者が配布する iOS アプリケーション「Blue Ticker」をいいます。

2. 「本 API」：本アプリが画面表示に必要な財務データ等を読み込むために呼び出す、運営者のサーバー上のデータ提供口をいいます（第三者への直接公開を目的とするものではありません）。

3. 「EDINET」：金融庁が運用する電子開示システム、および同システムを通じて提出された開示書類等をいいます。

4. 「有報」：有価証券報告書、および本サービスが取り込む範囲の関連書類（訂正報告書を含みます）をいいます。

5. 「利用者」：本アプリを利用するすべての者をいいます。

第3条（本サービスの内容）

1. 本サービスは、日本の発行体が EDINET に提出した有報等の公開情報を収集・抽出・加工・再構成し、運営者サーバー内に格納された範囲の財務情報および関連データを本アプリ上に提供するものです。

2. 本サービスの提供窓口は本アプリです。主な機能は以下のとおりです（未取り込みのデータ、一定の閾値未満のデータ、または非表示に設定されている項目は表示されません）。

  1. 銘柄の名称検索、条件検索、および直近の提出状況の一部表示
  2. 年次の財務サマリー（業績、資産、効率性等の各種指標）
  3. 前年差の要因分解（事業利益、ROIC、ROE 等）
  4. 有報等を元に生成された簡易的な会社説明
  5. 利用者が端末上で管理するウォッチリストおよび保有情報
  6. 保有株数に応じた業績目安の試算（本アプリ内でのローカル計算機能であり、サーバー上のポートフォリオ管理機能ではありません）

3. 本アプリはデータ表示のため、運営者のサーバー（本 API）へ HTTPS 通信を行います。本 API の第三者向け直接公開は本サービスの内容に含まれません。

4. 本サービスは、投資勧誘や金融商品の売買・助言を目的としたものではありません。運営者は、金融商品取引法上の金融商品取引業者（投資助言・代理業等）の登録を受けておらず、金融商品の仲介、募集、売買の執行、信用供与等は一切行いません。

第4条（本サービスに含まれないもの）

運営者は、以下の機能を本サービスの仕様として提供しません。利用者がこれらにアクセスできた場合であっても、運営者において提供維持や動作保証の義務は負いません。

  1. Web ブラウザ上で銘柄を閲覧できる Web アプリ機能、および RSS 配信
  2. リアルタイム株価、時価、ティックデータ、ニュース、位置情報連動機能
  3. 利用者アカウントの作成、およびウォッチリスト等のサーバー同期機能
  4. 第三者向けの一般公開用 REST API 製品
  5. 税務計算、確定申告、法令に基づく各種報告書の作成機能
  6. EDINET 原本の完全な再現、並びに全銘柄・全年度の完全な網羅

第5条（利用の制限および終了）

1. 運営者は、利用者が本規約に違反した場合、または本サービスの適切な運営を妨げたと判断した場合、予告なく当該利用者からのアクセス制限等の措置をとることができます。

2. 本サービスにはアカウントが存在しないため、個別の「退会手続き」はありません。利用を終了したい場合は、端末から本アプリを削除（アンインストール）してください。ローカルデータの消去等についてはプライバシー方針をご確認ください。

第6条（認証およびセキュリティ）

1. 本サービスは利用者アカウントを発行しないため、メールアドレスやパスワードによるログイン機能はありません。

2. 本アプリの正規利用の検証および不正アクセスの防止のため、Apple の App Attest や短期失効型の匿名トークンを使用することがあります。これらは広告配信や行動追跡を目的とするものではありません。

3. 利用者は、認証手順やレート制限（アクセス回数制限）を回避する行為、または第三者になりすまして本 API を呼び出す行為を行ってはなりません。

第7条（料金および費用）

1. 本サービスの基本利用料金は、現時点では無料です。

2. 本サービスの利用に必要な通信料、ならびに Apple ID や iCloud 等の利用に関する費用は、すべて利用者が負担するものとします。

3. 将来的に有料機能等を導入する場合は、あらかじめ本規約を改定して周知します。改定前の規約に基づき不当に料金を請求することはありません。

第8条（データの出所、加工、および表示の非保証）

1. 本サービスが表示する情報の主な出所は、EDINET に提出された日本市場の有報等です。

2. 運営者は、原本（XBRL や本文）から数値・内訳・注記等を抽出し、サマリーや要因分解の構築、ならびに会社説明の生成を行います。会社説明文は有報の「事業の内容」等を再構成したものであり、原文の直接的な引用でない場合があります。

3. 企業や業種によって異なる開示科目を比較しやすくするため、売上高や営業利益などの一般化された項目名に正規化（付け替え）を行う場合があります。そのため、画面上の項目名が各発行体の公式な科目名と一致しないことがあります。

4. データの抽出・加工・正規化・自動生成のプロセス、または訂正報告書の反映タイミング等により、画面表示が EDINET 原本と一致しない場合があります。運営者は、表示内容の完全性、正確性、最新性、および特定の利用目的への適合性を一切保証しません。

5. 事業利益の分解数値は、開示されている公式の営業利益と一致しない場合があります。また、アプリ内のファンド・保有株式画面における数値は、利用者が入力した単価や株数に基づき算出される「目安」であり、正確な時価評価や税務上の計算値ではありません。

6. 本サービスは、あくまで有価証券報告書等の原本を補完・閲覧しやすくするための補助ツールです。利用者は判断にあたり、必ず金融庁の EDINET 等で公式な原本を直接確認してください。

7. 利用者は、本サービスの表示内容を「公式の開示情報」であると誤認させるような態様で第三者に共有・再配布してはなりません。
