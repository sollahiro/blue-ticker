Blue Ticker 利用規約

最終更新: 2026-09-20
運営: Sorahiro Shuto

第1条（適用）

1. 本規約は、Sorahiro Shuto（以下「運営者」）が「Blue Ticker」の名称で提供するサービス（以下「本サービス」）の利用条件を定めます。

2. 利用者は、本サービスをダウンロードし、または画面を表示したときに、本規約に同意したものとします。アカウント登録はありません。

3. 本サービスのうち個人情報の取扱いは、免責とプライバシー方針 が優先します。本規約と矛盾する場合は、個人情報の取扱いについては同方針が、その他については本規約が、それぞれ適用されます。

4. iOS 版を App Store または TestFlight から入手した場合、Apple が定める利用条件も適用されます。Apple は本規約の当事者ではありません。

第2条（定義）

1. 「本アプリ」とは、運営者が配布する iOS アプリケーション「Blue Ticker」をいいます。

2. 「本 API」とは、本アプリが画面表示のため、財務その他の格納済みデータを取得するために呼び出す、運営者のサーバー上の読み取り口をいいます。第三者への提供を目的としません。

3. 「EDINET」とは、金融庁の電子開示システムおよびそこに提出された開示書類をいいます。

4. 「有報」とは、有価証券報告書および、本サービスが取り込む範囲の関連書類（訂正報告書を含みます）をいいます。

5. 「利用者」とは、本アプリを利用する者をいいます。

第3条（本サービスの内容）

1. 本サービスは、日本の発行体が EDINET に提出した有報等の公開情報を取り込み、抽出・加工・再構成した財務情報および関連表示を、格納済みの範囲で本アプリに提供します。

2. 製品として提供する接点は本アプリです。主な機能は次のとおりです。未取り込み、床未満、または画面に出していない項目は表示されません。

  1. 銘柄の名称検索、条件検索、直近の提出状況の一部表示
  2. 年次の財務サマリー（業績、資産、効率性）
  3. 前年差の要因分解（事業利益、ROIC、ROE）
  4. 短い会社説明
  5. 利用者が端末上で管理するリストおよび保有情報
  6. 保有株数に応じた業績の目安（本アプリ内の計算。サーバー上のポートフォリオ機能ではありません）

3. 本アプリは表示のため、運営者のサーバー（本 API）へ HTTPS でリクエストを送ります。本 API の第三者向け公開は、本サービスの内容ではありません。

4. 本サービスは、投資の勧誘のサービスではありません。金融商品の勧誘、投資助言、投資一任、仲介、募集、売買の執行、または信用供与を行いません。運営者は、金融商品取引法上の金融商品取引業者、投資助言・代理業その他の登録を受けていません。

第4条（本サービスに含まれないもの）

運営者は、次を本サービスの製品面として提供しません。利用者がこれらにアクセスできたとしても、本規約に基づく提供義務は生じません。

  1. ブラウザ上で銘柄を閲覧する Web アプリ、RSS
  2. 株価、時価、ティック、ニュース、位置情報に基づく機能
  3. 利用者アカウント、ウォッチリストのサーバー同期
  4. 第三者向けの REST API 製品
  5. 税務計算、法令に基づく報告書の作成
  6. EDINET 原本の完全な再現、全銘柄・全年次の網羅

第5条（利用の制限および終了）

1. 運営者は、本規約に違反した利用者、または本サービスの運用を妨げる利用者について、アクセスの制限その他の措置を取ることがあります。

2. アカウントがないため、個別の「退会」手続はありません。利用をやめたい場合は本アプリを削除してください。リストと保有情報の消し方はプライバシー方針に従います。

第6条（アカウントおよび認証）

1. 本サービスは利用者アカウントを発行しません。メールアドレスやパスワードによるログインはありません。

2. 本アプリの正規利用を確認し、不正利用を防ぐため、Apple の App Attest および短命の匿名トークンを使うことがあります。これは広告や行動追跡のためのものではありません。

3. 利用者は、認証やレート制限を回避し、または第三者になりすまして本 API を呼び出してはなりません。

第7条（料金）

1. 本サービスの利用料金は、現時点では発生しません。

2. 通信料、Apple ID および iCloud の利用に関する費用は、利用者が負担します。

3. 将来料金を設ける場合は、本規約を改定してからとします。改定前の条項だけで料金を発生させることはしません。

第8条（データの出所、加工、表示）

1. 本サービスが表示する財務その他の情報の主たる出所は、EDINET に提出された有報等です。対象は日本市場です。

2. 運営者は、XBRL および本文から数値・内訳・注記を抽出し、サマリーや要因分解を組み立て、会社説明を生成することがあります。会社説明は有報の「事業の内容」等を材料とした再構成であり、提出原文の引用そのものではありません。

3. 運営者は、企業または業種ごとに異なる開示項目を、比較のため売上高、営業利益その他の一般的な項目名に正規化することがあります。画面上の項目名は、当該発行体の開示上の科目名と一致しないことがあります。

4. 抽出、加工、再構成、正規化、生成、訂正報告書の反映タイミングにより、表示は EDINET の原本と一致しないことがあります。完全性、正確性、最新性、特定目的への適合性は保証しません。

5. 未格納または公開床に達していない会社・書類・指標は、表示しないか、エラーとなります。欠測を補完するために数字を捏造することは、本サービスの仕様ではありません。

6. 事業利益の分解は、開示されている営業利益と一致しない場合があります。

7. ファンド画面の純利益、純資産、投資元本、ファンドROEは、利用者が入力した株数および取得単価と、格納済みの年次指標から本アプリが計算する目安です。時価評価ではなく、税務上の数値でもありません。

8. 本サービスは有価証券報告書の原本の補助にすぎません。利用者は必ず原本も合わせて見てください。表示が原本と一致しないことがあります。

9. 利用者は、表示内容を公式開示であるかのように第三者へ提供してはなりません。

第9条（知的財産）

1. 本アプリ、画面、抽出・加工後の編成、要因分解、生成された会社説明、および運営者が作成した文書に関する権利は、運営者または正当な権利者に帰属します。

2. 有報の原文、XBRL、提出会社の商号・商標・ロゴ等の権利は、それぞれの権利者に帰属します。本サービスがこれらを表示することは、権利の移転ではありません。

3. 利用者がリストおよび保有情報として入力した内容は、利用者のものです。運営者のサーバーへは送信しません。iCloud 上の取扱いは Apple の条件とプライバシー方針に従います。

第10条（禁止事項）

利用者は、次の行為をしてはなりません。

  1. 法令、本規約、Apple または EDINET の利用条件に違反する行為
  2. 投資勧誘、無登録の投資助言、または本サービスを公式な開示・監査済み数値であるかのように表示する行為
  3. 本 API または本アプリの通信を、認証回避、過負荷、スクレイピング、自動化による大量取得など、通常の画面閲覧を超えて妨げる行為
  4. App Attest、トークン、アクセス制御、ログの改ざん、なりすまし
  5. 本サービスの出力を、運営者の許諾なく、独自の有料データ商品として再販売する行為
  6. 反社会的勢力への利益供与、またはこれに該当する者が本サービスを利用する行為
  7. その他、運営者が合理的に不適切と判断する行為

1. 本サービスは「現状有姿」で提供します。運営者は、表示の正確性、完全性、最新性、継続性、特定の投資成果、および障害が起きないことを保証しません。

3. 第8条のとおり、表示は有価証券報告書の原本と一致しないことがあります。原本との差異により生じた損害も、同様に補填しません。これは、本サービスが原本の補助にすぎず、利用者が必ず原本も合わせて見るべきことの帰結です。
