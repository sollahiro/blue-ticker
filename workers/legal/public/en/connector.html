YuhoLAB Connector for AI assistants

Last updated: 2026-11-08

Remote MCP server: https://mcp.yuholab.com/mcp · 日本語

What it is

The YuhoLAB Connector lets an AI assistant (such as Claude) read data on Japanese listed companies that YuhoLAB extracts from filings published on EDINET, the Financial Services Agency's disclosure system. It is a remote MCP server (Streamable HTTP). Information only, not investment advice.

Tools

All tools are read-only. The connector cannot write, change or delete anything, and it does not send data to other services on its own.

  • search_companies: Find listed companies by ticker code or name.
  • get_overview: Short company description.
  • get_filings: List of EDINET filings for a company.
  • get_filing_content: Section text of a filing.
  • get_financials: Annual financial summary (sales, operating profit, net profit, etc.).
  • get_waterfall: Year-over-year factor decomposition.
  • get_statement: Balance sheet, income statement, cash flow and equity statement items.
  • get_shares: EPS, diluted EPS, BPS and issued shares.
  • get_breakdown: Breakdown by segment, geography or employees.
  • get_feed_updates: Recent filings across companies.

Authentication and access

  • Users sign in with a Google account (OAuth 2.1 with PKCE). Other sign-in methods are not offered.
  • The purpose of sign-in is to identify each user so that access can be limited to prevent excessive use. Unlike an iOS app, a connector cannot use on-device attestation, so this is the substitute.
  • Access tokens are short-lived and are bound to this server. Disconnecting the connector in the AI service stops access.
  • The connector never receives the user's Google password.

Data handling

  • The content of conversations with the AI assistant is not stored. Only the parameters of each request (such as a ticker code) are processed to return a result.
  • Operational logs and usage counts are kept to apply usage limits and to operate the service.
  • Individual deletion requests cannot, in principle, be accommodated. See the privacy policy for details.
  • The data is processed from public information. Source: EDINET (Financial Services Agency). It may differ from the original filings; check EDINET for the primary documents.
