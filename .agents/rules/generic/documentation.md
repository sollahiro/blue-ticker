# ドキュメント

- Git 履歴をドキュメントに複製しない。現在の判断に必要な情報だけ残す。
- `AGENTS.md`＝原理原則、`.agents/rules/`＝実装時の禁止、`docs/`＝構成・運用・契約。rules にモジュール一覧や検証ログを置かない。
- `docs/` は教訓（再発防止）と契約を置く。件数・サイクル段階・公開ゲート・残作業の現在地は Linear Team `blue-ticker`（[トラッカー配置](https://linear.app/sollahiro/document/トラッカー配置-1890058f27b9)）。roadmap（JP: `blt-server-roadmap.md` / EU: `eu-esef-roadmap.md`）は方針・非ゴール・未決のみ。手順は deploy、結合点は operations。
- 残作業の正本は Linear。コード欠陥は GitHub Issue。セッション再開だけ handoff ローカルファイル（非追跡）。
