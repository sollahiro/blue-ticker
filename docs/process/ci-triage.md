# CI が赤いときの切り分け

2026-09-21 の規則。

**PR の差分だけから「なぜ CI が落ちたか」を断言しない。** 差分からの推測（例: HTML の変更だから legal rewrite テスト）は、本当に赤いジョブが別にあるときに誤診になる。

## 手順

1. 失敗した GitHub Actions の run を開く（Actions が見えない、または PAT が読めないときは、失敗した **ジョブ名** を先に聞く）。
2. 赤いジョブ名と、失敗したステップ / ログ行を名指しする。
3. それから原因と修正を対応づける。差分は補強証拠であり、最初の答えではない。

## やってはいけないこと

- ジョブ名を言う前に「たぶんあのスイート」と言う。
- あるスイートが緑であることだけを根拠に、別のスイートが失敗だと決める。
- CI 切り分けの名目でファイル全体をレビューする。

Actions が見えないときは、その旨を書いてジョブ名（または screenshot / URL）を頼む。変更ファイルからスイートを推測して埋めない。
