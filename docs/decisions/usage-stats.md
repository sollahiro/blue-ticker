# 利用統計（匿名集計）の方針

出典: 旧課題管理のチケット（移行日 2026-11-12）。当時の題名: 【コード】利用統計（匿名集計）: 銘柄・Tier・ツール別。
実装 Issue は GitHub [#701](https://github.com/sollahiro/blue-ticker/issues/701)。親は [#696](https://github.com/sollahiro/blue-ticker/issues/696)。関連: [#693](https://github.com/sollahiro/blue-ticker/issues/693)（同一内容の再書き込み禁止）、[#694](https://github.com/sollahiro/blue-ticker/issues/694)（filing-content の1行読み）、[#702](https://github.com/sollahiro/blue-ticker/issues/702)（エンドポイント×Tier）。
この文書は決定・契約の正本としてリポジトリで維持する。件数や進捗の最新値はここに書かない。

ユーザーを特定できない範囲で、利用の傾向を集計する（2026-10-31 確認）。

## 知りたいこと

* どの銘柄がよく調べられているか。
* Tier（Guest／Free／Paid。iOS は Free 相当）ごとの傾向。
* どのツール（API）がよく使われているか。AFM とサーバーLLMのどちらで呼ばれたか、失敗が多いツールはどれか。

## 集計の単位

* API・チャット: 日付、銘柄コード、Tier、エンドポイント（またはチャット）ごとの回数。
* チャット: どの銘柄について聞かれたか、AFM とサーバーLLMのどちらで答えたかの回数。
* ツール: 日付、Tier、ツール名、AFM かサーバーLLMか、成功か失敗かごとの回数。

## 匿名性のルール

* 端末キーIDやアカウントIDは統計に入れない。集計値だけを残し、個人を辿れる生ログは残さない。
* 質問の本文は保存しない。
* ツールの引数は、銘柄コード以外を残さない。
* 回数が少ない組み合わせ（珍しい銘柄×Tier など）は、表示時に合算するか非表示にして、個人を推測できないようにする。しきい値は要決定。

## 置き場所（案）

* Cloudflare Analytics Engine、または日次集計のテーブル。Neon は書き込みを増やしたくないので使わない。
* HAPIS ゲートウェイで記録する。AFM の利用は端末内で完結するため、アプリから集計用のイベント（銘柄コード、ツール名、成否だけ）を送る。

## 完了条件

* 銘柄別、Tier 別、ツール別の利用回数を、日単位で参照できる。
* 集計データから、端末やアカウントを特定できない。
