# Luna の正式終了

出典: 旧課題管理のチケット（移行日 2026-11-12）。当時の題名: Luna の正式終了。
この文書は決定・契約の正本としてリポジトリで維持する。件数や進捗の最新値はここに書かない。

## 現行

事業別セグメント（`SegmentInfoLLMNormalizer`）と地域別（`GeographyBreakdownLLMNormalizer`）は、Chat Completions を使わず決定論の表構造 + Jev 列選択。収益認識も同様。Luna を呼ぶ経路を戻すスイッチは残さない。履歴の検証レポートは `docs/case-studies/`。

残るのは、置き換え後に表示が消えていないことの確認と、fail-closed の needs_review の消化。進捗はオーナー管理のトラッカー Sheet。

## 目的（元チケット）

内訳 LLM から Luna（Chat Completions）を完全に外し、「表示されていた値が消えた書類はない」と言える状態にする。

## 現状（main `2d346f40`、2026-10-04 確認。履歴）

* 収益認識（`revenue_recognition_llm`）は Jev＋決定論に置き換え済み
* 当時、事業別のセグメント情報と地域別がまだ Luna を呼んでいた
* 置き換え前スナップショットとの比較で、v15 で表示が消えた書類あり。金額は旧 Luna と一致しており、表選択の閾値 0.9 で要確認として隠れている

## 当時の着手順

1. 収益認識の表選択の閾値を検証し直す
2. 「その他の源泉／その他の収益」の行の扱いを1つの方針で決める
3. 7416：括弧書きの説明が1行下の品目に付くずれを修正
4. 事業別セグメント情報・地域別の2経路を Jev＋決定論に置き換え、Luna の名残を削除

## 完了条件

* main に Luna を呼ぶ経路がない
* 本番の再構築後、旧データで表示されていた値が消えていないこと（スナップショット比較）
* レビュー担当が事業別・地域別の代表書類を PDF と照合して一致
