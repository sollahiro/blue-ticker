# REST 第三者公開（段階 B）

段階 A（自社向け REST 本線・Service Token・配布 CLI 廃止）は達成済み。達成済みの契約は次に委譲する（本ファイルに再叙述しない）:

- 認証の住み分け → `api-auth.md`
- 互換ポリシー → `api-compatibility.md`
- クライアント面の現構成 → `architecture.md`

## 定義

素性不明の第三者が自分のアプリに組み込める API へ移ること。3軸:

| 軸 | 内容 |
|---|---|
| 認証の主体転換 | 第三者の機械は **API キー**、またはキーなし **x402**（払済みレシート）。顧客の Apple ID とキー台帳は別。iOS ログインは持たない |
| 契約の安定化 | 後方互換の約束を厳格化（段階 B で deprecation 期間等を足す） |
| 利用制御 | レート制限（未払い 402 連打も含む）。キーは台帳、キーなしは x402 の従量 |

REST をエンドポイント単位で有料マスクしない。**段階 B の対象は第三者 REST**。iOS の一部画面（レポート等）は IAP で、こちらに載せない。MCP は開発専用で x402 対象外。

土台（バックフィル・ストレージ）が未成熟なうちに不特定多数へ開放しない。着手順・公開判断は Linear Team `blue-ticker`。認証の表は `api-auth.md`。索引は `blt-server-roadmap.md`。
